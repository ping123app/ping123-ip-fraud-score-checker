## What Is an IP Fraud Score?

An IP fraud score is a risk-oriented summary of signals that may affect account creation, login checks, fraud prevention, trust and safety decisions, and QA testing.

Ping123 helps inspect:

- Public IP and network owner
- Country, ASN, ISP, and organization
- Proxy, VPN, hosting, datacenter, and suspicious network labels
- IP reputation and blacklist context
- DNS leak and WebRTC leak behavior
- Browser language and time zone coherence

## IP Fraud Score Review Checklist

```text
IP fraud score review

[ ] IP address and network route are expected
[ ] Proxy/VPN/datacenter classification is understood
[ ] IP reputation and blacklist context are acceptable
[ ] DNS behavior matches the visible route
[ ] WebRTC does not reveal unexpected network information
[ ] Browser context does not contradict the IP region
```

## FAQ

### Is IP fraud score the same for every website?

No. Different systems weigh proxy, VPN, reputation, ASN, DNS, WebRTC, device, and behavior signals differently.

### What causes a high IP fraud score?

Common contributors include datacenter infrastructure, known proxy or VPN ranges, abuse history, blacklist signals, DNS mismatch, WebRTC mismatch, or incoherent browser context.
